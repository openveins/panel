# AGENTS.md — OpenVeins Panel

## Stack
- **Runtime/Build:** Bun 1.x, Vite 8
- **UI:** React 19, TanStack Router v1, TanStack Form, TanStack Table
- **Styling:** Tailwind CSS v4 + shadcn/ui (radix-lyra, mauve base)
- **Auth:** Cookie-based (`withCredentials: true`), no localStorage tokens
- **Validation:** Zod v4
- **State:** Contexts only (Auth, Dashboard, Health) — no Redux/Zustand
- **HTTP:** Axios (single shared `api` instance)

## Commands (use `bun`, never `npm`/`yarn`)
| Command | What it does |
|---|---|
| `bun run dev` | Vite dev server, proxies `/api` → `http://localhost:8080` |
| `bun run build` | `tsc -b && vite build` — type-check **before** bundle |
| `bun run lint` | ESLint 9 flat config |
| `bun run preview` | Vite preview of built `dist/` |

- No test framework, no formatter (no Prettier), no pre-commit hooks.

## Routes (file-based, TanStack Router)
- Route files in `src/routes/`, auto-generate `src/routeTree.gen.ts`
- `routeTree.gen.ts` is **generated by `@tanstack/router-plugin/vite`** and committed to git. After adding/moving a route file, run `bun run dev` (or the plugin will do it on next dev server start) and commit the updated `routeTree.gen.ts`.
- Route tree: `/` → redirect, `/auth/*` (login, 2FA, register), `/dashboard/*` (users, locations, profile, settings, nodes placeholder).

## Code Conventions
- **Path alias:** `@/` → `src/` (set in both `tsconfig.json` and `vite.config.ts`)
- **Imports:** `verbatimModuleSyntax: true` in tsconfig — use `import type` for type-only imports.
- **API client:** `import { api } from '@/api/client'` — Axios instance, baseURL `""`, `withCredentials: true`.
- **CSS:** Tailwind v4 `@import` directives in `src/styles.css`, CSS variables in `oklch`, dark mode via `.dark` class.
- **Forms:** TanStack Form + Zod schemas.
- **Components:** shadcn/ui in `src/components/ui/`, patterns from `shadcn` CLI + radix-lyra style.

## Key Files Map
| File | Role |
|---|---|
| `src/main.tsx` | App entry, creates Router + renders |
| `src/routes/__root.tsx` | Root layout, provider hierarchy |
| `src/contexts/auth-context.tsx` | Auth state + login/logout/2FA |
| `src/contexts/dashboard-context.tsx` | CRUD for users/locations/settings/2FA |
| `src/contexts/health-context.tsx` | Backend health check on mount |
| `src/api/client.ts` | Axios instance (cookie auth) |
| `src/types/Types.ts` | Shared types (`ApiResponse<T>`, `User`, etc.) |
| `src/lib/templates/static.ts` | Sidebar + settings page static data |
| `src/styles.css` | Global styles + CSS variables |

## CI / Deploy
- **Jenkins:** `bun install` → `bun run build` → `scp dist/*` to deploy host
- **Docker:** multi-stage (Bun → nginx), expects `nginx.conf` at repo root (⚠️ file is **missing**)

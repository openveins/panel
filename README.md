## Openveins
Open source and fully features game hosting panel solution for begginers and professionals.

## 🚧 Active developement
This project is in really early developement with little to no functions. There is no official release yet as this repository holds a skeleton for the project.


### Planned features:
- Drop in replacement for Pterodactyl® panel
    - Native support for [Wings](https://github.com/pterodactyl/wings)
    - Migration from Pterodactyl® panel to OpenVeins.
- Out-of-the-box docker support
- Custom server management service planned
